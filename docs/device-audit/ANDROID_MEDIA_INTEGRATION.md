# LastWave Native: Android Media Integration Architecture

**Audit Date:** 2026-11-12  
**Device:** Motorola Moto G45 5G (Android 16, SDK 36)

---

## 1. Foreground Service Architecture

Android 14, 15, and 16 enforce strict constraints on background execution. Media playback requires explicit foreground service declarations:

### 1.1 Manifest Declaration:
```xml
<service
    android:name=".playback.MusicPlaybackService"
    android:exported="true"
    android:stopWithTask="false"
    android:foregroundServiceType="mediaPlayback">
    <intent-filter>
        <action android:name="android.media.browse.MediaBrowserService" />
        <action android:name="android.intent.action.MEDIA_BUTTON" />
    </intent-filter>
</service>
```

### 1.2 Service Implementation Patterns:
- In `MusicPlaybackService.kt`, the service inherits from `androidx.media.MediaBrowserServiceCompat`.
- When playback starts, `startForeground(NOTIFICATION_ID, notification, ServiceInfo.FOREGROUND_SERVICE_TYPE_MEDIA_PLAYBACK)` is invoked.
- `stopWithTask="false"` allows the service to continue playing audio even if the user clears the main task card from the Android Recents overview.

## 2. Media Notification Specification

```
NotificationRecord(pkg=com.lastwave.app, id=4102, channel=lastwave_playback_v3, category=transport, flags=ONGOING_EVENT|ONLY_ALERT_ONCE|NO_CLEAR|FOREGROUND_SERVICE|NO_DISMISS)
```

- **Notification Channel:** `lastwave_playback_v3` (Importance: `IMPORTANCE_LOW` / 3 so audio notifications never produce an annoying beep while starting songs).
- **Style:** `androidx.media.app.NotificationCompat.MediaStyle`
- **Actions Declared (6 total):**
  1. Favorite / Like track
  2. Skip to Previous
  3. Play / Pause toggle
  4. Skip to Next
  5. Repeat mode cycle
  6. Stop / Dismiss playback
- **Compact View Actions:** Actions 1, 2, 3 displayed in condensed notification shade.
- **Dynamic Palette Tinting:** The notification accent color (`0xffdfc3c3`) is dynamically generated by analyzing the album artwork bitmap via `androidx.palette.graphics.Palette`.

## 3. MediaSessionCompat Transport Integration

- **Session Tag:** `LastWavePlayer`
- **Supported Transport Controls:**
  - `PlaybackStateCompat.ACTION_PLAY_PAUSE`
  - `PlaybackStateCompat.ACTION_PLAY`
  - `PlaybackStateCompat.ACTION_PAUSE`
  - `PlaybackStateCompat.ACTION_SKIP_TO_NEXT`
  - `PlaybackStateCompat.ACTION_SKIP_TO_PREVIOUS`
  - `PlaybackStateCompat.ACTION_SEEK_TO`
  - `PlaybackStateCompat.ACTION_SET_REPEAT_MODE`
  - `PlaybackStateCompat.ACTION_SET_SHUFFLE_MODE`
  - `PlaybackStateCompat.ACTION_SET_RATING`
- **Metadata Published:**
  - `MediaMetadataCompat.METADATA_KEY_TITLE`

  - `MediaMetadataCompat.METADATA_KEY_ALBUM`
  - `MediaMetadataCompat.METADATA_KEY_DURATION`
  - `MediaMetadataCompat.METADATA_KEY_ALBUM_ART` (Bitmap)

## 4. Audio Focus & Peripheral Handling

- **Request Focus:**
  - Request: `AudioFocusRequestCompat.Builder(AudioManagerCompat.AUDIOFOCUS_GAIN)`
  - AudioAttributes: `AudioAttributesCompat.USAGE_MEDIA`, `CONTENT_TYPE_MUSIC`
- **Loss Handling:**
  - `AUDIOFOCUS_LOSS_TRANSIENT`: Pause playback temporarily (e.g. navigation prompt).
  - `AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK`: Reduce volume to 25% until focus regained.
  - `AUDIOFOCUS_LOSS`: Pause playback and abandon focus.
- **Noisy Audio Broadcast:**
  - Listens for `AudioManager.ACTION_AUDIO_BECOMING_NOISY`.
  - Automatically pauses audio when wired headphones or Bluetooth earbuds disconnect.
